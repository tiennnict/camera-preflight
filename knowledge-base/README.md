# Knowledge base

Curated reference data per camera model (R-07, D-40). Every value carries a source and a
confidence; a value without a source is not accepted by the validator. A missing entry never
blocks a check: the app falls back to what it can derive from the user's own photos.

## Adding a model

1. Copy `TEMPLATE.yaml` to `<brand>/<model>.yaml` (`canon/`, `nikon/` or `sony/`).
2. Fill in only what you can source. Leave a field out rather than guess it.
3. Run `uv run python tools/kb.py validate`.
4. Open a pull request. State each source in the description.

AF point layouts go in `layouts/<name>.yaml` with normalised coordinates (0 to 1); an entry
refers to one with `af.layout_ref`.

`schema/` holds the JSON Schema generated by `uv run python tools/kb.py schema`.

## Status

30 entries (checked 2026-10-19), mostly known issues from manufacturer service notices: Nikon
D5000, D600, D750, D800E, D810, Z 6, Z 7, Z 8, Z 9, Z6III, Z5II; Canon EOS 5D, 5D Mark II,
5D Mark III, 6D, 7D, 7D Mark II, EOS-1D X, 70D, 650D, 750D, 760D, R10, R50; Sony a9, a7 III,
a7 IV, a7R III; and the D7200 and D800 with owner reports labelled `low`. Some Canon and Sony pages
refuse automated access; where a notice was read through a copy, the confidence is `medium`.

No maker notice was found for these bodies, so they have no entry yet: Nikon D7000, D7100, D7500,
D850, D780, Z 5, Z 50; Canon 5D Mark IV, 6D Mark II, 80D, 90D, EOS R, RP, R5, R6; Sony a7 II,
a7R II, a7R IV, a6000 to a6600, a7S series. Canon Marketing Japan's quality notice list
(canon.jp/support/quality-info) and Nikon Imaging Japan's notice list
(nij.nikon.com/support/whatsnew/information) can be read automatically and are the most complete.

A known issue may name the units it concerns (D-50):

- `serials`: inclusive ranges as the manufacturer lists them (`first`, `last`, digits only);
- `serial_pattern`: a regular expression on the serial digits, for rules such as "first digit 0
  and sixth digit 1 or 2";
- `firmware_from` and `firmware_below`: the firmware versions it concerns;
- `serviced_mark` and `lookup_url`: how a repaired unit is marked, and the maker's serial checker.

The app shows an issue only when it may concern the unit, as a warning to check with the named
test, never as a verdict. Low-confidence issues are shown as owner reports.
