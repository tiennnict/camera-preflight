# Knowledge base

Curated reference data per camera model (R-07, D-40). Every value carries a source and a
confidence; a value without a source is not accepted by the validator. A missing entry never
blocks a check: the app falls back to what it can derive from the user's own photos.

## Adding a model

1. Copy `TEMPLATE.yaml` to `<brand>/<model>.yaml` (`canon/`, `nikon/` or `sony/`).
2. Fill in only what you can source. Leave a field out rather than guess it.
3. Run `uv run python tools/kb.py validate`.
4. Open a pull request. State each source in the description.

AF point layouts go in `layouts/<name>.yaml` with normalised coordinates (0 to 1); an entry
refers to one with `af.layout_ref`.

`schema/` holds the JSON Schema generated by `uv run python tools/kb.py schema`.
